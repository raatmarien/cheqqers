# Cheqqers

In this repository you can find the code for the online version of Cheqqers hosted at [cheqqers.com](https://cheqqers.com). If you are interested in the original code referenced in our paper [Quantum Checkers: The Development and Analysis of a Quantum Combinatorial Game](https://ieeexplore.ieee.org/document/11114278), then you should take a look at [the version tagged cog-paper-version here](https://github.com/raatmarien/cheqqers/tree/cog-paper-version).

If you want to run the new web version locally, you can find more information in the `frontend` folder.
